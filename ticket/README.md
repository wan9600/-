# 고연전 티켓 장터

고려대·연세대 학생들이 고연전(정기전) 티켓을 **정가 이하로** 양도·구매하는 웹사이트입니다.
화면은 GitHub Pages에서, 로그인과 데이터는 Firebase(무료 요금제로 시작 가능)에서 처리합니다.
모든 학생이 같은 거래글·채팅·후기를 실시간으로 봅니다.

- `index.html`, `style.css`, `app.js` : 사이트
- `firebase-config.js` : **Firebase 연결 정보 (직접 채워야 함)**
- `firestore.rules` : 서버 보안 규칙 (Firebase 콘솔에 붙여넣음)
- `demo/` : 서버 없이 한 브라우저 안에서만 동작하는 체험판

## 기능
- **학교 메일 인증 가입**: `@korea.ac.kr`, `@yonsei.ac.kr` 메일만 가입 가능, 메일 인증을 마쳐야 글쓰기·채팅 가능. 학교는 메일 주소로 자동 결정
- **거래글**: 팝니다/삽니다, 종목(야구·아이스하키·농구·럭비·축구·패키지), 경기일, 좌석, 수량, 정가/가격, 거래 방법, 장소, 사진 3장
- **암표 방지**: 정가를 초과하는 가격은 화면과 서버 규칙 양쪽에서 거부
- **목록**: 종류·종목 필터, 검색, 정렬, 완료 거래 숨기기, 끌어올리기
- **실시간 채팅**: 읽음 표시, 빠른 답장, 선입금·계좌 요구 경고 → 예약중 → 거래완료
- **상호 후기**(거래 당사자만, 1회), 찜하기, 링크 공유, 사이트 내 알림
- **신고 & 관리자**: 글 숨김, 이용 제한, 신고 처리
- 다크 모드, 모바일 대응

## 운영 준비 (처음 한 번, 약 15분)

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에서 **프로젝트 추가** (Google 애널리틱스는 꺼도 됩니다)
2. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**
   - **로그인 방법** 탭 → **이메일/비밀번호** → 사용 설정 → 저장
   - **설정** 탭 → **승인된 도메인** → `wan9600.github.io` 추가
   - (선택) **템플릿** 탭 → 이메일 주소 인증 → 언어를 한국어로
3. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)` 권장
   - **프로덕션 모드**로 시작
   - 만든 뒤 **규칙** 탭에서 기존 내용을 지우고 `firestore.rules` 파일 내용을 전부 붙여넣고 **게시**
   - **색인** 탭 → **복합 색인 만들기**: 컬렉션 `posts`, 필드 `hidden` 오름차순 + `bumpedAt` 내림차순, 쿼리 범위 컬렉션
     (빠뜨려도 사이트 첫 화면에 색인 만들기 링크가 표시됩니다. 만드는 데 몇 분 걸립니다)

### 2. 사이트에 연결하기
1. Firebase 콘솔 **프로젝트 설정(톱니바퀴) → 일반 → 내 앱 → 웹(`</>`) 앱 추가** (호스팅 설정은 체크하지 않음)
2. 화면에 나오는 `firebaseConfig` 값을 `firebase-config.js` 에 붙여넣고 커밋합니다.
   이 값은 공개되어도 괜찮은 식별자이고, 데이터 보호는 보안 규칙이 담당합니다.

### 3. GitHub Pages 켜기
저장소 **Settings → Pages → Deploy from a branch** 에서 브랜치를 고르고 저장합니다.
1~2분 뒤 `https://wan9600.github.io/-/ticket/` 로 접속할 수 있습니다.

### 4. 관리자 지정
1. 사이트에서 운영자 본인 학교 메일로 가입합니다.
2. Firebase 콘솔 **Authentication → 사용자** 에서 내 계정의 **사용자 UID** 를 복사합니다.
3. **Firestore Database → 데이터 → 컬렉션 시작**: 컬렉션 ID `admins`, 문서 ID에 복사한 UID, 필드는 아무거나 하나(예: `memo` = `운영자`) → 저장
4. 사이트를 새로고침하면 상단에 **관리** 메뉴가 생깁니다.

## 설정 바꾸기
- `app.js` 상단 `CONFIG`
  - `eventStart`: `'YYYY-MM-DD'` 로 지정하면 첫 화면에 D-day 표시
  - `maxQty`, `maxImages`, `bumpCooldownMin`, `listLimit`
- 가입 가능한 학교 메일을 바꾸려면 `firebase-config.js` 의 `SCHOOL_DOMAINS` 와 `firestore.rules` 의 `schoolEmail()`, `schoolOf()` 를 함께 고친 뒤 규칙을 다시 게시하세요.

## 비용과 한도
무료(Spark) 요금제로 시작할 수 있습니다. Firestore는 하루 읽기 5만 건·쓰기 2만 건까지 무료입니다.
목록 화면을 한 번 열 때 거래글 수만큼 읽기가 발생하므로, 거래글 300개 기준으로 하루 방문 약 150회를 넘기면 한도에 닿을 수 있습니다.
그보다 붐빌 것 같으면 콘솔에서 종량제(Blaze)로 바꾸세요. 초과분은 읽기 10만 건당 100원 안팎이고, 예산 알림을 걸어두면 안전합니다.

## 알아둘 점
- 인증 메일이 학교 메일 서버에서 스팸으로 분류될 수 있습니다. 이용 안내에 스팸함 확인을 적어두었습니다.
- 알림은 사이트 안에서만 보입니다(푸시·메일 알림 없음).
- 탈퇴해도 상대방과의 채팅 기록은 남습니다.
- 데이터 백업은 Firebase 콘솔의 Firestore **가져오기/내보내기**(종량제 필요) 또는 **재해 복구** 기능을 이용하세요.

## 개발자용: 로컬 테스트
Firebase 에뮬레이터로 실제 프로젝트 없이 테스트할 수 있습니다 (Java 필요).
```bash
cd ticket
npx firebase-tools emulators:start --only auth,firestore --project demo-kyt
# 다른 터미널에서
python3 -m http.server 8000
# 브라우저: http://localhost:8000/?emulator
```
에뮬레이터에서는 인증 메일 링크가 에뮬레이터 로그에 출력됩니다.
