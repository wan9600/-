# 고연전 티켓 장터

고려대·연세대 학생들이 고연전(정기전) 티켓을 **정가 이하로** 양도·구매하는 웹사이트입니다.
서버 없이 `index.html` / `style.css` / `app.js` 만으로 동작하며, GitHub Pages 등 정적 호스팅에 그대로 올리면 됩니다.

## 기능
- **회원**: 회원가입(아이디·비밀번호·닉네임·학교·학번), 로그인/로그아웃, 프로필·비밀번호 변경, 데이터 내보내기, 탈퇴
- **거래글**: 팝니다/삽니다, 종목(야구·아이스하키·농구·럭비·축구·패키지), 경기일, 좌석, 수량, 정가/가격, 거래 방법, 장소, 사진(최대 3장, 자동 축소)
- **암표 방지**: 정가를 초과하는 가격은 등록 불가, 정가 이하 거래는 할인율 표시
- **목록**: 종류·종목 필터, 검색, 정렬(최신/가격/인기/경기일), 완료 거래 숨기기, 끌어올리기
- **거래 진행**: 채팅(읽음 표시, 빠른 답장, 사기 의심 문구 경고) → 예약중 → 거래완료
- **신뢰도**: 거래 후 상호 후기(별점), 프로필에 평점·거래 횟수 표시
- **찜하기, 링크 공유, 알림**(새 채팅, 예약/완료, 후기, 관심 종목 새 글)
- **신고 & 관리자**: 글/사용자 신고, 관리자 페이지에서 글 숨김·이용 제한·신고 처리, 전체 백업/복원/초기화
- 다크 모드, 모바일 대응

## 체험 계정
| 아이디 | 비밀번호 | 비고 |
|---|---|---|
| tiger24, eagle23, crimson, blueblue | demo1234 | 일반 회원 |
| admin | admin1234 | 관리자 |

처음 접속하면 예시 데이터가 채워집니다. 관리자 페이지의 **초기화**로 되돌릴 수 있습니다.
실제 운영 전에는 관리자 비밀번호를 바꾸세요.

## 설정
`app.js` 상단 `CONFIG` 에서 조정합니다.
- `eventStart`: `'YYYY-MM-DD'` 로 지정하면 첫 화면에 D-day 표시
- `maxPriceRatio`: 정가 대비 허용 가격 (기본 1.0 = 정가 초과 금지)
- `maxQty`, `maxImages`, `bumpCooldownMin`

## 알아둘 점
모든 데이터는 **각 사용자 브라우저의 localStorage** 에 저장됩니다. 같은 브라우저의 여러 탭 사이에서는 실시간 동기화되지만,
다른 사람·다른 기기와는 공유되지 않습니다. 여러 사람이 실제로 함께 쓰려면 `app.js` 의 저장소 영역(`loadDb`/`save`)을
Firebase·Supabase 같은 백엔드로 교체해야 하며, 비밀번호 확인과 권한 검사도 서버에서 해야 합니다.
